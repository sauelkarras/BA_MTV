MTV Checker GUI

Build a command-line call interactively and run your Rocq/Haskell-based MTV checker on UCI datasets.
CLI-backed

Dataset selection

Use either a named dataset (German Credit / Bank Marketing) or a generic UCI line (e.g. adult = fetch_ucirepo(id=2)).

Matches the CLI flag --dataset <name>.

Parsed into --uci-line "var = fetch_ucirepo(id=N)".

Note Do not set both at once: the tool enforces mutual exclusion.

Range checks

Closed interval per column, using Coq in_range.
Each check is of the form attr,lo,hi, e.g. 13,18,60 or 2,0,inf. The GUI will generate --range flags accordingly.

Pointwise contradictions

Premise ⇒ conclusion on two attributes.
Numeric premise example: attr1 > 70 and target attr2 = retired gives attr1>70=>attr2=retired.
Categorical premise example: attr7 = A75 and attr6 != A65 gives attr7=A75=>attr6!=A65.

Class balance

Per-label expected share with tolerance.
Each entry is turned into --class "attr,label,expected_share,tolerance". Example: 21,1,0.5,0.1 on German Credit's class column.
